These are commands/requests you can ask Claude to perform for this project.

--------------------------------------------------------------------------------
SESSION MANAGEMENT (Restart & Resume)
--------------------------------------------------------------------------------
| Command / Action                 | Description                               |
|----------------------------------|-------------------------------------------|
| /exit                            | Exit Claude Code (session auto-saved)     |
| claude --continue                | Restart and resume last session           |
| claude                           | Start fresh session                       |
| /resume                          | Show recent sessions to pick from         |
| /context                         | Show current context/token usage          |
| Ctrl+C                           | Force close (session still saved)         |

HOW TO RESTART WITHOUT LOSING HISTORY:
  Option 1: Type /exit, then run: claude --continue
  Option 2: Close terminal, reopen, run: claude --continue
  Option 3: Run: claude, then type: /resume

Session files saved at: C:\Users\munge\.claude\projects\
