================================================================================
TROUBLESHOOTING
================================================================================

Backend won't start:
  1. Check venv is activated: (venv) should show in prompt
  2. Check port 7071 is free: kill other func process
  3. Run: python test_import.py

Frontend won't start:
  1. Run: npm install
  2. Check port 3000 is free
  3. Clear cache: rm -rf node_modules && npm install

CORS errors:
  1. Restart backend: Ctrl+C then func start
  2. Check local.settings.json has CORS configured

Login not working:
  1. Check Azure AD app registration
  2. Verify redirect URI is http://localhost:3000
  3. Ensure it's set as "Single-page application" type
