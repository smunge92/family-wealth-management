# Screenshots

Place your app screenshots here. These are referenced by the main README.md.

## Required Screenshots

| Filename | Description | How to Capture |
|----------|-------------|----------------|
| `dashboard.png` | Full dashboard view | Navigate to Dashboard, scroll to show summary cards + charts |
| `transactions.png` | Transaction list | Navigate to Transactions, show a few categorized transactions |
| `accounts.png` | Connected accounts | Navigate to Accounts, show connected bank accounts |
| `planning.png` | AI financial planning | Navigate to Planning, show an AI analysis result |
| `spending-by-category.png` | Category bar chart | Scroll down on Dashboard to the full-width bar chart |
| `login.png` | Login page | Sign out, capture the login screen |

## Tips for Great Screenshots

- Use a **1280x800** or **1920x1080** browser window for consistent sizing
- Make sure there's **real data visible** (transactions, balances, charts populated)
- Use **Chrome DevTools** (F12 > toggle device toolbar) to set exact viewport size
- Use **Windows Snipping Tool** (Win+Shift+S) or browser extension for clean captures
- Crop out browser chrome (address bar, tabs) for a cleaner look
- Save as **PNG** for crisp text rendering
